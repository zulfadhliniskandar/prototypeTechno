How to Connect Multiple Phone Cameras
Option A — Connect Phones via IP Address (IP Webcam / DroidCam)

Install IP Webcam on Phone 1, Phone 2, etc. Tap Start server on each phone to see its IP (e.g. 192.168.1.50:8080). Click + Connect Phone IP in SafeWatch and add each phone to its room.

Option B — Zero-Install Phone Browser Camera

Scan the QR code in + Connect Phone IP → Browser QR from any smartphone. Each phone registers with its IP address and streams live to SafeWatch's YOLOv11-Pose fall detector.

Automatic Photo & Video Evidence

When any connected phone detects a fall, SafeWatch immediately captures a photo + H.264 MP4 video clip and pushes an audible real-time alert to this caregiver dashboard.
